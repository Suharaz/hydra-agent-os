# Evidence Bundle — Phase 8 Verification

This directory contains the artefacts produced during the Phase 8 soak and verification run.

## Files

| File | Generated by | Description |
|------|-------------|-------------|
| `latency.csv` | `bun run latency-report` | Per-order latency rows: `order_id,venue,status,t_sent_ns,t_ack_ns,latency_ms`. One row per ACK'd order in the look-back window. |
| `ledger-export.json` | `bun run export-ledger` | Full JSON dump of all ledger tables (capped at 5 000 rows each). Includes `rowCount` per table for audit. |
| `soak-summary.md` | `scripts/soak.sh` | Start/end timestamps, scenario pass/fail counts, RSS min/max/drift, reconcile result, and latency p95 verdict. |
| `soak-logs/hydra.log` | `scripts/soak.sh` | Raw stdout/stderr of the HYDRA demo process during the soak. |
| `soak-logs/scenarios.log` | `scripts/soak.sh` | CLI scenario run output (scenarios 1, 3, 4 every 20 min). |
| `soak-logs/rss.log` | `scripts/soak.sh` | RSS memory samples every 5 min. |
| `soak-logs/reconcile.log` | `scripts/soak.sh` | Output of `reconcile.ts` at end-of-soak. |
| `soak-logs/latency-report.log` | `scripts/soak.sh` | Output of `latency-report.ts` at end-of-soak. |
| `soak-logs/export-ledger.log` | `scripts/soak.sh` | Output of `export-ledger.ts` at end-of-soak. |

## How to Regenerate

```bash
# Latency report (last 24 h, default output path)
bun run latency-report

# Latency report (custom window and path)
bun run latency-report -- --since 6 --out docs/evidence/latency.csv

# Full ledger export
bun run export-ledger

# Reconcile (exit 0 clean, 1 diffs, 2 UNVERIFIED when no venue keys — never counts as clean)
bun run reconcile

# API key permission check (requires BINANCE_SPOT_API_KEY/SECRET)
bun run apikey-check

# Full soak (6 h by default; set SOAK_HOURS=1 for a quick smoke)
SOAK_HOURS=1 bash scripts/soak.sh
```

## Phase 8 Success Criteria Checklist

Operator fills these in after the real soak run.

- [ ] **Soak stability** — 0 unhandled rejections or crashes over 6 h in demo mode
- [ ] **Memory flat** — RSS drift < 50 MB across the soak (`soak-summary.md`)
- [ ] **Reconcile clean** — `reconcile.ts` exits 0 (diff = 0) at end of a soak run WITH venue keys; exit 2 (UNVERIFIED) does not satisfy this item
- [ ] **Single fill per trade** — after a simulated 20 s network drop, exactly one fill row per order
- [ ] **Scenario coverage** — scenarios 1, 3, 4 all PASS at least once during soak
- [ ] **Shadow A/B rows** — `agent_runs` contains shadow-role rows; `pnl_1h_usd` back-filled
- [ ] **Latency p95 ≤ 300 ms** — confirmed in `latency-report` output (document actual value)
- [ ] **VPS recommendation noted** — latency note added to README if VN workstation exceeds target
- [ ] **Secrets scan clean** — `git log --all` contains no credentials; `.env.example` demo-only values only
- [ ] **Live boot refuses over-privileged key** — `apikey-check.ts` exits 1 when `enableWithdrawals=true`
- [ ] **IP whitelist warning fires** — `apikey-check.ts` prints WARN when `ipRestrict=false`
- [ ] **Dashboard LAN lockout** — `curl` from another LAN host returns 401/connection refused
- [ ] **Kill-switch drill ×2** — time-to-flat and residue recorded (one drill under simulated 429)
- [ ] **`cli unkill` path exercised** — ledger shows `system.unkill` event
- [ ] **Evidence bundle committed** — this directory pushed to the repo
